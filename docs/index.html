The problem

Data is scattered

Mental-health data lives across CDC, SAMHSA, and 50+ state portals — each with its own schema, API, and quirks.

Discovery is broken

Keyword search on Socrata catalogs misses 80% of relevant datasets. Researchers don't know what they don't know.

Analysis is slow

Even after finding data, joining and querying it requires SQL, Python, and hours of cleaning per question.

What we built

An end-to-end pipeline that ingests, indexes, and serves mental-health data as a conversational interface.

Intelligent ingestion

An LLM agent generates 100+ semantic queries to discover relevant CDC/SAMHSA datasets, then ingests them as Parquet into S3-compatible storage.

How it works

  1. Discover — An LLM agent generates diverse mental-health queries and searches CDC + SAMHSA Socrata catalogs.
  2. Ingest — Each dataset is downloaded as Parquet and stored in MinIO under raw/{org}/{uid}.parquet.
  3. Index — Metadata and row chunks are embedded (1536-dim) and written to pgvector for similarity search.
  4. Query — A user asks a question. The RAG layer retrieves relevant chunks and an LLM generates a grounded answer with citations.

Run the model

Option 1 — Use the hosted app (recommended)

Just visit the live demo. The app auto-loads the entire CDC + SAMHSA mental-health catalog on startup and answers natural-language questions live. Nothing to install.

Option 2 — Deploy your own copy (free, 2 minutes)

  1. Go to share.streamlit.io and sign in with GitHub
  2. Click New app → pick this repo → set Main file to demo.py
  3. Under Advanced settings → Secrets, add: OPENAI_API_KEY = "sk-..."
  4. Click Deploy — you get a public URL in ~2 min

Option 3 — Run the full stack locally

git clone https://github.com/sriya19/alfa8-final-mental-health-platform.git
cd alfa8-final-mental-health-platform
cp .env.example .env   # add your OPENAI_API_KEY
docker-compose up -d
# open http://localhost:8501 (Streamlit UI)
#      http://localhost:8000/docs (API)
